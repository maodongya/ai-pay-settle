## 1. 模块开发规范

### 1.1 服务接入层

- **输入：** RocketMQ 异步 + HTTP 同步兜底
- **输出：** 标准化 trade_bill + 投递清算任务 Topic
- **幂等：** bill_no 唯一索引，重复消息直接返回成功

### 1.2 公共服务管理

- 校验：商户资质有效、金额 ≥ 0、分润比例总和 ≤ 100%
- 审批：规则/结算方案变更必须双人审批
- 告警：堆积、打款失败、收益波动 ±30%、负收益

### 1.3 算账服务

- 分片键：`merchant_id % shard_count`
- 任务状态：PENDING → RUNNING → SUCCESS / FAILED
- 失败重试：指数退避，最多 5 次

### 1.4 计费子系统

- 规则热更新：审批通过后写 DB + 删 Redis 缓存键
- 匹配失败：使用平台默认兜底规则，记录 WARN 日志

### 1.5 结算系统

- 余额变更必须写 account_flow 流水
- 冻结/解冻/扣减在同一事务内完成
- 乐观锁 version 字段防并发

## 3. MQ 消息规范

### 3.1 Topic 清单

| Topic | 生产者 | 消费者 | 说明 |
|-------|--------|--------|------|
| trade_pay_topic | 支付渠道 | 接入层 | 支付流水 |
| trade_refund_topic | 支付渠道 | 接入层 | 退款流水 |
| clearance_task_topic | 接入层 | 算账服务 | 清算任务 |
| settle_amount_topic | 清分服务 | 结算服务 | 待结算金额 |
| payment_result_topic | 银行渠道 | 结算服务 | 打款结果回调 |

### 3.2 消息体模板（trade_pay_topic）

```json
{
  "billNo": "CL2026070500001",
  "billType": 1,
  "businessLine": "A",
  "category": "A01",
  "serviceItem": "A0101",
  "merchantId": 100001,
  "agentId": 200001,
  "secondAgentId": null,
  "orderNo": "OD20260705123456",
  "tradeAmount": 1000.00,
  "cityCode": "110000",
  "payChannel": "ALI_PAY",
  "payTime": "2026-07-05T14:30:00"
}
```

### 3.3 消费规范

- 消费幂等：先查 bill_no 是否已存在
- 重试：最多 16 次，间隔 1s/5s/10s/30s/1m/2m...
- 超限：转入 DLQ `trade_pay_topic_DLQ`，触发告警

```
POST /api/settlement/withdraw/apply
Authorization: Bearer {token}
```

请求：

```json
{
  "withdrawAmount": 5000.00,
  "settleCardNo": "6222****1234"
}
```

响应：

```json
{
  "code": 0,

    "waitBalance": 15000.00,

    "status": 1
```

## 6. 核心业务伪代码

### 6.1 阶梯递减分润

```java
public BigDecimal calcStepDownShare(
        BigDecimal firstMonthVal,
        BigDecimal stepDown,
        BigDecimal minShare,
        int merchantJoinMonths) {
    BigDecimal current = firstMonthVal
        .subtract(stepDown.multiply(BigDecimal.valueOf(merchantJoinMonths - 1)));
    return current.compareTo(minShare) < 0 ? minShare : current;
}
```

### 6.2 完整分润计算

```java
public FeeCalcResult calc(FeeCalcDTO req, AgentRelation rel, List<FeeShareRule> rules) {
    BigDecimal net = req.getTradeAmount();

    // 1. 平台手续费
    FeeShareRule platformRule = matchRule(rules, req, TARGET_PLATFORM);
    BigDecimal platformFee = calcByMode(net, platformRule);
    net = net.subtract(platformFee);

    // 2. 一级代理
    BigDecimal l1Share = BigDecimal.ZERO;
    if (rel.getAgentId() != null) {
        FeeShareRule l1Rule = matchRule(rules, req, TARGET_AGENT_L1);
        l1Share = calcByMode(net, l1Rule);
        net = net.subtract(l1Share);
    }

    // 3. 二级代理
    BigDecimal l2Share = BigDecimal.ZERO;
    if (rel.getSecondAgentId() != null) {
        FeeShareRule l2Rule = matchRule(rules, req, TARGET_AGENT_L2);
        l2Share = calcByMode(net, l2Rule);
        net = net.subtract(l2Share);
    }

    // 4. 合伙人阶梯递减
    BigDecimal partnerShare = BigDecimal.ZERO;
    if (rel.getSplitPartyId() != null) {
        FeeShareRule pRule = matchRule(rules, req, TARGET_PARTNER);
        int months = getMerchantJoinMonths(req.getMerchantId());
        BigDecimal rate = calcStepDownShare(
            pRule.getFirstMonthValue(), pRule.getStepDownVal(),
            pRule.getMinShare(), months);
        partnerShare = net.multiply(rate);
        net = net.subtract(partnerShare);
    }

    assertNonNegative(net, platformFee, l1Share, l2Share, partnerShare);
    return new FeeCalcResult(platformFee, l1Share, l2Share, partnerShare, net);
}
```

### 6.3 中间户余额更新（乐观锁）

```java
@Transactional
public void creditBalance(Long merchantId, String billNo, BigDecimal amount) {
    // 幂等检查
    if (accountFlowRepo.exists(billNo, OP_CREDIT)) return;

    MerchantSettleAccount account = accountRepo.findByMerchantId(merchantId);
    BigDecimal before = account.getWaitBalance();
    BigDecimal after = before.add(amount);

    int rows = accountRepo.updateBalance(
        merchantId, after, account.getVersion()); // WHERE version = ?
    if (rows == 0) throw new OptimisticLockException();

    accountFlowRepo.insert(merchantId, billNo, OP_CREDIT, amount, before, after);
}
```

### 6.4 D0 提现流程

```java
@Transactional
public String withdraw(Long merchantId, BigDecimal amount) {
    MerchantSettleAccount acc = accountRepo.findByMerchantId(merchantId);
    if (acc.getWaitBalance().compareTo(amount) < 0)
        throw new BizException(30001, "余额不足");

    // 冻结
    accountRepo.freeze(merchantId, amount, acc.getVersion());

    String settleNo = generateSettleNo();
    settlementOrderRepo.create(settleNo, merchantId, amount, MODE_D0);

    // 异步提交银行出款
    mqProducer.send(PAYMENT_REQUEST_TOPIC, new PaymentRequest(settleNo, amount));
    return settleNo;
}
```

```java
@Transactional
public void onPaymentFailed(String settleNo, String failReason) {
    SettlementOrder order = orderRepo.findBySettleNo(settleNo);
    if (order.getStatus() == STATUS_FAILED) return; // 幂等

    accountRepo.unfreeze(order.getMerchantId(), order.getSettleAmount());
    orderRepo.updateStatus(settleNo, STATUS_FAILED, failReason);
    alertService.send(ALERT_PAYMENT_FAIL, settleNo + ": " + failReason);
}
```
