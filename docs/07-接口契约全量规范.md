# 接口契约全量规范

> 版本：V1.2 | 约定：JSON UTF-8，金额 Number 类型，时间 ISO-8601 +08:00

---

## 1. 通用约定

### 1.1 HTTP 响应 envelope

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "traceId": "7f3a2b1c",
  "timestamp": "2026-07-05T14:30:00+08:00"
}
```

### 1.2 分页

请求：`pageNum`（从1开始）、`pageSize`（默认20，最大100）

响应 data：

```json
{
  "list": [],
  "total": 100,
  "pageNum": 1,
  "pageSize": 20
}
```

### 1.3 鉴权

| 端 | 方式 |
|----|------|
| 商户 API | Header `Authorization: Bearer {jwt}`，JWT 含 merchantId |
| 操作台 | Header `Authorization: Bearer {token}` + RBAC |
| 银行回调 | Header `X-Signature: Base64(RSA-SHA256(body))` |
| 内部 Dubbo | 信任域，携带 traceId |

## 2. 上游接入 HTTP（同步兜底）

### POST /api/v1/clearance/bill/submit

支付渠道/交易系统同步推送，MQ 不可用时的兜底。

**请求：**

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| billNo | string | 是 | ^CL\d{14,20}$ |
| billType | int | 是 | 1-8 |
| businessLine | string | 是 | max 32 |
| category | string | 是 | max 32 |
| serviceItem | string | 是 | max 32 |
| merchantId | long | 是 | >0 |
| orderNo | string | 是 | max 64 |
| tradeAmount | decimal | 是 | >0，2位小数 |
| cityCode | string | 是 | 6位国标或 * |
| payChannel | string | 否 | |
| payTime | datetime | 是 | |
| originBillNo | string | 退款必填 | |

**响应 data：** `{ "billNo": "CL...", "status": 0, "accepted": true }`

**错误码：** 10001 重复单据，10002 参数非法，10003 商户不存在

## 3. 商户端 API

### 3.1 GET /api/v1/settlement/account/balance

**响应 data：**

```json
{
  "merchantId": 100001,
  "waitBalance": 15000.00,
  "frozenBalance": 0.00,
  "availableBalance": 15000.00,
  "settleMode": 2,
  "minWithdraw": 100.00
}
```

### 3.2 POST /api/v1/settlement/withdraw/apply

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| withdrawAmount | decimal | 是 | ≥ minWithdraw |
| settleCardNo | string | 否 | 不传用默认签约卡 |

**响应 data：**

```json
{
  "applyNo": "WD2026070500000001",
  "settleNo": "ST2026070500000001",
  "status": 1,
  "waitBalance": 10000.00,
  "frozenBalance": 5000.00
}
```

### 3.3 GET /api/v1/settlement/withdraw/{applyNo}

查询提现状态。

### 3.4 GET /api/v1/settlement/flow/list

| 参数 | 说明 |
|------|------|
| startDate | yyyy-MM-dd |
| endDate | yyyy-MM-dd |
| opType | 可选 |

### 3.5 GET /api/v1/settlement/reconcile/list

对账单列表。

### 3.6 GET /api/v1/settlement/reconcile/download

| 参数 | 说明 |
|------|------|
| billDate | yyyy-MM-dd |

响应：`Content-Type: application/pdf` 或 `{ "downloadUrl": "https://..." }`

## 4. 操作台 API

### 4.1 POST /api/v1/console/fee-rule/draft

保存草稿，status=草稿。

### 4.2 POST /api/v1/console/fee-rule/submit

提交审批，status=待审。

### 4.3 POST /api/v1/console/fee-rule/audit

| 字段 | 说明 |
|------|------|
| ruleId | |
| action | APPROVE / REJECT |
| remark | 驳回必填 |

### 4.4 POST /api/v1/console/fee-rule/preview

试算，body 同 submit + `tradeAmount`、`merchantId`。

**响应：** 完整 FeeCalcResultDTO。

### 4.5 GET /api/v1/console/clearance/bill/list

筛选：merchantId、billNo、status、dateRange、pageNum、pageSize。

### 4.6 GET /api/v1/console/clearance/bill/{billNo}/detail

含 trade_bill + fee_calc_result + split_detail。

### 4.7 POST /api/v1/console/settlement/repay

手动重出款。

| 字段 | 说明 |
|------|------|
| originSettleNo | 原失败单 |
| remark | |

需财务角色 + 审批流（>5万）。

### 4.8 GET /api/v1/console/alert/list

告警列表，支持 status、level 筛选。
